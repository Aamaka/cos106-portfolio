Projects

Projects from my GitHub, built while learning Java and Spring Boot at Semicolon Africa. The images are illustrations of how each project works.

Kolo: banking API

A REST API for a simple bank. Customers can register, log in, deposit, withdraw, check their balance and transfer money to another account.

Each new customer gets a generated 10-digit account number. Transfers check the sender’s password and balance before moving money, and invalid amounts are rejected with clear error messages.

  • Java
  • Spring Boot
  • MongoDB
  • Lombok
View code on GitHub

mogbo: party planning API

A backend for planning parties. People sign up with their email, log in, and create parties with a name and location.

Every party is saved and linked to the user who created it, and duplicate sign-ups are blocked. Responses use a consistent success-or-error format, and the project includes tests that run against an embedded MongoDB database.

  • Java
  • Spring Boot
  • Maven
  • MongoDB
  • JUnit
View code on GitHub

School: student registration app

An application for registering students at a school. Each record stores the student’s name, email, age, class grade, school fees and the amount paid so far.

Students can’t be registered twice with the same email, and staff can look up every student in a particular grade.

  • Java
  • Spring Boot
  • MongoDB
  • REST APIs
